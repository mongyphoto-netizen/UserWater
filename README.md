# แบบประเมินศักยภาพองค์กรผู้ใช้น้ำ

เว็บไซต์สำหรับทำแบบประเมินองค์กรผู้ใช้น้ำ 20 ข้อ

## วิธีการใช้งาน
เว็บไซต์นี้เป็น HTML แบบคงที่ (Static HTML) ไม่จำเป็นต้องติดตั้งโปรแกรมใดๆ
สามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์เพื่อใช้งานได้ทันที

## การนำขึ้นเว็บไซต์ (Deploy)
ให้ใช้ **GitHub Pages** โดยเลือกตั้งค่า:
1. Source: Deploy from a branch
2. Branch: main และเลือกโฟลเดอร์ / (root)
